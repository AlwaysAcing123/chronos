# IBM Plex fonts

Unmodified WOFF2 assets from [IBM Plex](https://github.com/IBM/plex), revision
`763c36ef9117782905ae010056dfbe8fd2653a25`.

- Sans Regular, Medium, SemiBold: `packages/plex-sans/fonts/complete/woff2/`
- Mono Regular: `packages/plex-mono/fonts/complete/woff2/`

The SIL Open Font License in `LICENSE.txt` covers these files. They are served
locally: the browser makes no request to a third-party font service.
